# ADR 001. Схема из сущностей через ddl-auto, а не Flyway

## Контекст

Требуется, чтобы схема PostgreSQL создавалась автоматически на основе JPA-моделей:
«при запуске приложения схема базы данных должна автоматически создаваться/обновляться
на основе моделей (при необходимости можно использовать spring.jpa.hibernate.ddl-auto)».

Обычно применяются миграции (Flyway или Liquibase): они версионируемы,
воспроизводимы и не зависят от текущего состояния сущностей.

## Решение

Использовать `spring.jpa.hibernate.ddl-auto`:

- `dev`: `update`, схема достраивается при старте;
- `test`: `create-drop`, чистая схема на каждый прогон.

Flyway не подключается.

## Последствия

Плюсы:

- ровно то поведение, которое требуется, без расхождений с проверкой;
- один источник правды: сущности;
- для проверки достаточно запустить приложение.

Минусы:

- `update` не удаляет лишние колонки и не откатывает изменения;
- нет истории миграций, `update` на больших схемах рискован.

## Что бы изменилось в продакшене

Добавились бы `V1__init.sql` с полной схемой, `ddl-auto: validate` и Flyway в пайплайне.
Модель сущностей осталась бы той же, поэтому переход не требует переписывания кода.
